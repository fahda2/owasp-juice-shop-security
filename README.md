# OWASP Juice Shop Security Testing

## Overview
This project demonstrates hands-on security testing of OWASP Juice Shop, a deliberately vulnerable web application.

## Environment
- Local machine
- Docker container
- Burp Suite Community
- Chromium browser

## Vulnerabilities Identified
- SQL Injection (Authentication Bypass)
- Reflected Cross-Site Scripting (XSS) (In progress)
- Sensitive Data Exposure (In progress)

## Skills Demonstrated
- Web application security testing
- OWASP Top 10 analysis
- HTTP request inspection using Burp Suite
- Security documentation and reporting

⚠️ All testing was performed in a controlled and legal environment.
